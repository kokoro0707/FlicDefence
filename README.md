#Flick Defence

##概要
フリック操作でミサイルを発射し、
空から降ってくる隕石を狙撃する2Dアクションゲームです。

隕石が地面に到達するとゲームオーバーになります。

---

##操作方法

ドラッグ開始
フリック
指を離す
ミサイル発射

##使用環境
unity6
C#
TextMeshPro
Particle System
